## Single-worker lifecycle
After first strict idle gate (two stable checks), run all seven cases in one process, retaining the same NPU Context. Between cases reset Graphs, synchronize, collect unreachable Python owners, empty allocator cache and synchronize. Read-only resource gate accepts a single recognized Python process matching the worker PID (host or container ID) or an empty process list; unknown/INVALID rows, unhealthy device, busy device or HBM >8192 MB always block. Operator exclusive reservation remains required. No reset/kill of foreign processes. If an old INVALID record persists before initial launch, obtain administrator clearance first; this change does not bypass it. Matrix total timeout 6300s, per-case JSON retained. Re-run Smoke to establish new lifecycle baseline. Device kernels and numerical/performance criteria unchanged.
